# Beetle Run

Description: ​You're just a little guy - in fact, you're a beetle! You've found yourself in the middle of a parade with giant humans stepping all around you in a big mob. Dodge them to avoid getting squished! Once you're squished, there's no going back :( Reload the tab to play again!

Controls:
- Up arrow key - Up
- Down arrow key - Down​
- Left arrow key - Left
- Right arrow key - Right
